#Weather App
 A modern weather application built with HTML, CSS and JavaScript

 ## Features
 -Search weather by city
 -Real time weather data
 -Dynamic weather backgrounds
 -Weather condition icons
 -Temperature
 -Feels like temperature
 -Humidity
 -Wind speed
 -Atmospheric pressure
 -Visibility
 -Sunrise & Sunset time
 -Max & Min temperature
 -Local city time
 -Country detection
 -Responsive design

 ##Technologies
 -HTML5
 -CSS3
 -JavaScript
 -OpenWeather API
